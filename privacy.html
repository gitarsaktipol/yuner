Kebijakan Privasi FerTune

Berlaku sejak 27 September 2026

Singkatnya: FerTune tidak mengumpulkan, tidak menyimpan di server, dan tidak membagikan data pribadi apa pun. Semua proses terjadi di perangkatmu sendiri.

Tentang aplikasi ini

FerTune adalah aplikasi untuk belajar musik: tuner gitar, latihan membaca not balok dan not angka, serta membuat partitur. FerTune bisa dipakai oleh anak-anak maupun orang dewasa. FerTune tidak memiliki akun, tidak menampilkan iklan, dan tidak memiliki pembelian di dalam aplikasi.

Mikrofon

Mikrofon dipakai hanya saat kamu menekan tombol "Aktifkan mikrofon", untuk mengenali nada yang kamu mainkan (tuner dan latihan membaca not).

  • Suara dianalisis langsung di perangkat, detik itu juga.
  • Suara tidak pernah direkam, tidak disimpan, dan tidak dikirim ke mana pun.
  • Mikrofon berhenti saat kamu menekan "Matikan mikrofon" atau pindah ke menu Partitur.

Keyboard / alat musik MIDI

Jika kamu menghubungkan keyboard MIDI, FerTune hanya membaca tuts yang ditekan untuk menilai latihan dan mengisi partitur. Data ini diproses di perangkat dan tidak dikirim ke mana pun.

Data yang disimpan di perangkat

FerTune menyimpan beberapa hal hanya di penyimpanan perangkatmu, supaya tidak hilang saat aplikasi ditutup:

  • Partitur yang kamu buat atau impor.
  • Pengaturan (misalnya tuning, tangga nada, level Arcade, jenis notasi).

Data ini tidak pernah dikirim ke server. Kamu bisa menghapusnya kapan saja dengan menghapus partitur di aplikasi, menghapus data aplikasi di pengaturan HP, atau mencopot pemasangan (uninstall) FerTune.

File yang kamu pilih

Saat kamu mengimpor file MIDI atau memilih gambar partitur, file itu dibuka di perangkat saja. Saat mengekspor ke MIDI, file disimpan ke perangkatmu. Tidak ada yang diunggah.

Tidak ada pelacakan, iklan, atau pihak ketiga

  • Tidak ada iklan.
  • Tidak ada analitik atau pelacakan penggunaan.
  • Tidak ada layanan pihak ketiga yang menerima data dari aplikasi.
  • Tidak ada fitur obrolan, berbagi, atau tautan ke media sosial.

Seperti semua aplikasi yang diunduh dari internet, file aplikasi FerTune diambil dari server hosting (GitHub Pages) saat pertama kali dipasang dan saat ada pembaruan. Server hosting dapat mencatat informasi teknis standar (seperti alamat IP) untuk keperluan keamanan dan operasional mereka; FerTune sendiri tidak menerima atau menggunakan informasi tersebut.

Anak-anak

FerTune dirancang aman untuk anak-anak. Karena FerTune tidak mengumpulkan data pribadi apa pun, tidak ada data anak yang dikumpulkan, disimpan di server, atau dibagikan.

Perubahan kebijakan

Jika kebijakan ini berubah, versi terbaru akan dipasang di halaman ini dengan tanggal berlaku yang baru.
