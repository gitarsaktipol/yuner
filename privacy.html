Kebijakan Privasi FerTune

Berlaku sejak 2 Oktober 2026

Singkatnya: tanpa akun, semua data FerTune hanya ada di perangkatmu. Jika kamu memilih masuk dengan akun Gitar Sakti, email dan partitur milikmu disimpan di server Gitar Sakti agar tidak hilang saat ganti HP. Suara mikrofon tidak pernah direkam atau dikirim.

Tentang aplikasi ini

FerTune adalah aplikasi untuk belajar musik: tuner gitar, latihan membaca not balok dan not angka, serta membuat partitur. FerTune ditujukan untuk pengguna berusia 13 tahun ke atas. Memakai FerTune tidak mewajibkan akun. Akun bersifat opsional dan sama dengan akun di gitarsakti.com. FerTune tidak menampilkan iklan dan tidak memiliki pembelian di dalam aplikasi.

Mikrofon

Mikrofon dipakai hanya saat kamu menekan tombol "Aktifkan mikrofon", untuk mengenali nada yang kamu mainkan (tuner dan latihan membaca not).

  • Suara dianalisis langsung di perangkat, detik itu juga.
  • Suara tidak pernah direkam, tidak disimpan, dan tidak dikirim ke mana pun.
  • Mikrofon berhenti saat kamu menekan "Matikan mikrofon" atau pindah ke menu Partitur.

Keyboard / alat musik MIDI

Jika kamu menghubungkan keyboard MIDI, FerTune hanya membaca tuts yang ditekan untuk menilai latihan dan mengisi partitur. Data ini diproses di perangkat dan tidak dikirim ke mana pun.

Data yang disimpan di perangkat

FerTune menyimpan beberapa hal hanya di penyimpanan perangkatmu, supaya tidak hilang saat aplikasi ditutup:

  • Partitur yang kamu buat atau impor.
  • Pengaturan (misalnya tuning, tangga nada, level Arcade, jenis notasi).

Selama kamu tidak masuk dengan akun, data ini tidak pernah dikirim ke server. Kamu bisa menghapusnya kapan saja dengan menghapus partitur di aplikasi, menghapus data aplikasi di pengaturan HP, atau mencopot pemasangan (uninstall) FerTune.

Akun dan penyimpanan cloud (opsional)

Jika kamu menekan Masuk atau Daftar di menu Partitur, FerTune memakai akun Gitar Sakti (gitarsakti.com):

  • Yang dikirim dan disimpan: alamat email, kata sandi (disimpan terenkripsi oleh penyedia autentikasi, tidak terbaca oleh kami), nama jika kamu mengisinya, dan partitur yang kamu buat atau impor beserta judul dan pengaturannya.
  • Tujuan: masuk ke akun dan menyimpan partitur supaya tersedia di semua perangkatmu.
  • Tempat penyimpanan: server Supabase yang dikelola Gitar Sakti. Hanya akunmu yang dapat membaca dan mengubah partituranmu; data ini tidak dijual dan tidak dibagikan ke pihak lain.
  • Menghapus data: menghapus partitur di aplikasi juga menandainya terhapus di cloud. Untuk menghapus akun beserta seluruh partitur di cloud, tekan Hapus akun di kartu akun menu Partitur, atau buka halaman hapus akun (bisa tanpa memasang aplikasi). Karena akunnya sama dengan akun Gitar Sakti: bila kamu pernah membeli kelas, akun tidak dihapus (riwayat pembelian wajib disimpan) dan hanya data FerTune di cloud yang dihapus. Kamu juga bisa meminta lewat email di bagian Kontak.
  • Kamu bisa keluar kapan saja; partitur di perangkat tetap ada.
  • Umpan balik saat hapus akun (opsional): kalau kamu mengisi alasan menghapus akun, alasan dan catatanmu disimpan tanpa nama, tanpa email, dan tanpa tautan ke akunmu, hanya untuk memperbaiki FerTune. Boleh dikosongkan.

Suara dari mikrofon dan data keyboard MIDI tetap tidak pernah dikirim ke server.

File yang kamu pilih

Saat kamu mengimpor file MIDI atau memilih gambar partitur, file itu dibuka di perangkat saja. Saat mengekspor ke MIDI, file disimpan ke perangkatmu. File itu sendiri tidak diunggah; hanya partitur hasil impor yang ikut tersimpan di cloud jika kamu sedang masuk dengan akun.

Tidak ada pelacakan, iklan, atau pihak ketiga

  • Tidak ada iklan.
  • Tidak ada analitik atau pelacakan penggunaan.
  • Satu-satunya layanan di luar perangkat adalah server akun Gitar Sakti (Supabase) di atas, dan hanya dipakai jika kamu masuk.
  • Tidak ada fitur obrolan, berbagi, atau tautan ke media sosial.

Seperti semua aplikasi yang diunduh dari internet, file aplikasi FerTune diambil dari server hosting (GitHub Pages) saat pertama kali dipasang dan saat ada pembaruan. Server hosting dapat mencatat informasi teknis standar (seperti alamat IP) untuk keperluan keamanan dan operasional mereka; FerTune sendiri tidak menerima atau menggunakan informasi tersebut. Jika dibuka lewat gitarsakti.com, hosting dilakukan oleh Vercel dengan catatan teknis serupa.

Anak-anak

FerTune tidak ditujukan untuk anak di bawah usia 13 tahun dan kami tidak dengan sengaja mengumpulkan data pribadi dari mereka. FerTune hanya mengumpulkan email dan partitur dari pengguna yang memilih membuat akun. Jika kami mengetahui ada data anak di bawah 13 tahun yang terkumpul, data itu akan dihapus.
